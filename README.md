**Vortex Pago Único** is a high-performance, visually stunning landing page built with modern web technologies. Designed for a seamless user experience, it features smooth animations, glassmorphism, and a robust component architecture.

---

## ✨ Key Features

- 🚀 **Modern Tech Stack**: Built with Next.js 16 and Tailwind CSS 4.
- 🎨 **Premium UI/UX**: Utilizing Radix UI and Framer Motion for sophisticated interactions.
- 📱 **Fully Responsive**: Optimized for all devices, from mobile to desktop.
- ⚡ **Lazy Loading**: Components are dynamically loaded below the fold for lightning-fast performance.
- 🛠️ **Modular Design**: Clean and reusable component structure.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Components**: [Radix UI](https://www.radix-ui.com/) & [Lucide Icons](https://lucide.dev/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Forms**: [React Hook Form](https://react-hook-form.com/) & [Zod](https://zod.dev/)

## 🚀 Getting Started

To get the project running locally, follow these steps:

### Prerequisites

- [Node.js](https://nodejs.org/) (v18+)
- [pnpm](https://pnpm.io/) (recommended)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/ezemendozalems-coder/vortex-pago-unico.git
   ```
2. Navigate to the project directory:
   ```bash
   cd vortex-pago-unico
   ```
3. Install dependencies:
   ```bash
   pnpm install
   ```

### Development

Run the development server:

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 📦 Project Structure

- `/app`: Next.js App Router and page layouts.
- `/components`: Reusable UI components and section layouts.
- `/hooks`: Custom React hooks.
- `/lib`: Utility functions and configuration.
- `/public`: Static assets (images, fonts, etc.).
- `/styles`: Global CSS and theme configuration.
